# 🛒 CartShare

**CartShare** is a collaborative shopping web application that allows users to create or join a shared shopping room, manage a common cart, and track group activities.

It is designed for students, office teams, travel groups, roommates, and anyone who needs to coordinate a group purchase.

---

## 📌 About the Project

Managing group purchases using WhatsApp messages, notes, or spreadsheets can lead to missed items, duplicate purchases, and confusion about who added what.

CartShare provides a centralized platform where users can collaborate on a shared shopping cart.

The project was developed as part of **Internship Studio**.

---

## ✨ Features

* 🏠 **Create a Room** – Create a unique room for group shopping.
* 🔑 **Join a Room** – Join an existing room using a room code.
* 🛒 **Shared Cart** – Add and remove items from the common cart.
* 🔄 **Cart Synchronization** – Keep cart changes synchronized across browser tabs.
* 📋 **Activity Log** – Track actions performed by participants.
* 🧾 **Printable Receipt** – Generate a clean receipt summary for the group.
* 📱 **Responsive Design** – Works on desktop, tablet, and mobile devices.
* 💾 **Data Persistence** – Store cart information using browser storage.

The features are based on the provided CartShare project requirements.

---

## 🧪 How to Test

1. Open CartShare.
2. Create a new room.
3. Copy the generated room code.
4. Open another browser tab/window.
5. Join the same room.
6. Add or remove items from the cart.
7. Check the activity log.
8. Generate and print the receipt.

The project requirements specify testing the Room functionality across multiple browser sessions.
